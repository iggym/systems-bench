Agent Trace Inspector

Renders an exported agent trace — spans with parent/child nesting, timing, tokens, cost, and status — as a nested waterfall timeline. Click a row for full span details; the ★ critical path is highlighted. Consumes the shared agentTrace schema (see README).

Schema: spans[] with id, parent, type (llm|tool|loop|eval|handoff|plan|act), name, startedAt (ISO or epoch ms), durationMs, model, tokensIn/Out, costUsd, status, error, input/output, attrs. Timing = as recorded in your log; totals = computed here, not billed.

Trace waterfall IDLE 
Click any span row to inspect it.

Waterfall is positioned by start time with bar width ∝ duration. ★ = on the critical path (longest root→leaf chain — the part that paces your end-to-end latency). Errors are dashed-red; timeouts are hatched. A static renderer of exported traces — no live ingestion.

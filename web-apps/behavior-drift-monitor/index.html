Agent Behavior Drift Monitor

Detects distribution shifts in agent behavior from a daily/weekly aggregate timeline — tool usage, refusal rate, error rate, response length, cost, model mix. Baseline (first half) vs recent (second half), per-metric delta, drift score, and interpretation hints. The agent-behavior analog of Pipeline Rot.

Schema: series[] of {date, metrics:{key: number}}. Keys must be consistent across rows; rates should be 0–1. Baseline = first half of points, recent = second half. Relative change below the threshold is ignored; a metric that goes from zero to non-zero is flagged "emerged".

MCP Client Inspector

Compiles raw tool definitions into OpenAI-style function schemas or Gemini FunctionDeclarations as you type — with nested objects/arrays, enums, defaults, and required-flag handling.

COMPILED

Drop OpenAI output into your client's tools array; Gemini output into tools.declarations. Nested objects and arrays (including arrays of objects) are recursed automatically; required arrays are emitted only when non-empty. Gemini output omits default.

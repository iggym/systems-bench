JSON Schema Repair Loop

Validate a payload against a JSON Schema subset, classify each violation, apply targeted auto-repairs (type coercion, enum nearest-match, default insertion, extra-property stripping), then re-validate — up to N passes — with a complete repair log. Violations without a safe repair are reported as unresolved, never silently forced.

Repair rules are conservative: string→number coercion, enum nearest-match (Levenshtein) with fallback to schema default, required-key insertion from default (or a marked null placeholder), and extra-property stripping only when additionalProperties: false. Unresolvable violations stop the loop and are listed.

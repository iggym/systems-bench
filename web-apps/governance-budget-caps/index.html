Governance & Budget Caps

Evaluate an agent-usage log against a policy: monthly budget with warning threshold, per-model caps, forbidden actions, HITL escalation triggers, and output-validation rules. Produces an enforcement decision for every event (ALLOW / WARN / HITL / BLOCK / BLOCK_BUDGET), spend projections, and a violations list. Local, deterministic.

Enforcement report IDLE 

    
Decision order per event: forbidden action → BLOCK; HITL trigger → HITL (requires human); per-model cap or budget cap exceeded → BLOCK_BUDGET; spend ≥ warn% → WARN; else ALLOW. Output validation (required keys / must-not-contain) is applied when output is present. This is a policy simulator — wire the same rules into your gateway for real enforcement.

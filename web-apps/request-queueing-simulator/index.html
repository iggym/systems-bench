Request Queueing Simulator

Model queue behavior under load with priorities, timeouts, and backpressure. Input arrival rate, service time, queue limits; outputs queue depth, wait times, rejection rate, SLA violations. Local, deterministic.

Queue simulation results READY 

    
Simulate request queue under load. Arrival rate > service rate creates backlog. Queue depth grows until timeout or max-depth is hit, causing rejections. SLA = requests served within timeout. Priority queues improve high-priority latencies at the cost of fairness.

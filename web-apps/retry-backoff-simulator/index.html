Retry/Backoff & Rate-Limit Simulator

Model retry storms, exponential backoff, jitter, and 429 rate-limit handling. Input a request log and policy; outputs retry timeline, cost impact, and success rate. Local, deterministic.

Retry simulation report IDLE 

    
Retry storms happen when concurrent requests fail with 429, then all retry at the same time. This simulator models exponential backoff (with optional jitter) to spread retries and reduce thundering herd. Cost includes original + retry attempts. Success rate = requests that eventually succeeded.
